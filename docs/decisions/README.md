# ADRs — Architecture Decision Records

Short records of why the repo is shaped the way it is. One decision per file,
numbered, never rewritten (supersede with a new file).

Format:

```markdown
# 000N: Title
Date: YYYY-MM-DD
Status: accepted | superseded by 000M

## Context
What forced a decision.

## Decision
What we chose.

## Consequences
What this costs or enables.
```
